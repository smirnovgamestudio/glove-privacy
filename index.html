1. О приложении

Glove for Dating (идентификатор com.glove.dating) — автономное учебное приложение для совершеннолетних, содержащее уроки, тесты и интерактивные диалоги с вымышленными персонажами. Издатель: Doloto. Контакт: uliamarudova804@gmail.com.

Для локального профиля приложение запрашивает имя, возраст, пол, страну и учебную цель. Также на устройстве сохраняются выбранный язык, результаты занятий, прогресс и настройки приложения. Эти сведения используются для персонализации упражнений и восстановления локального состояния.

3. Передача данных

В проверенной офлайн-версии приложения профиль и результаты занятий обрабатываются на устройстве и не отправляются на сервер разработчика. Приложение не предназначено для общения с реальными людьми. Перед публикацией окончательной версии необходимо проверить, что добавленные библиотеки и службы не изменяют этот порядок; если изменяют, этот раздел должен быть обновлён.

4. Хранение и удаление

Данные хранятся в локальном хранилище приложения. Прогресс может быть сброшен в приложении, если соответствующая функция доступна в установленной версии. Удаление приложения обычно удаляет его локальные данные; если включено резервное копирование Android, отдельные данные могут восстанавливаться средствами системы. Для вопросов об удалении данных обращайтесь по адресу uliamarudova804@gmail.com.

5. Дети

Glove предназначен для пользователей 18 лет и старше; приложение не предназначено для детей.

6. Безопасность и изменения

Мы стремимся ограничивать обработку данных объёмом, необходимым для функций приложения. Эта политика может обновляться при изменении функциональности. Актуальная версия размещается по тому же публичному URL.

Privacy Policy

November 12, 2026

1. About the app

Glove for Dating (package ID com.glove.dating) is an offline educational app for adults, featuring lessons, quizzes and scripted conversations with fictional characters. Publisher: Doloto. Contact: uliamarudova804@gmail.com.

2. Data entered by users

To create a local profile, the app asks for a name, age, gender, country and learning goal. The selected language, lesson and dialogue progress, results and app settings are also stored on the device. This information supports local personalization and progress tracking.

3. Data transmission

In the reviewed offline version, profile and learning data are processed on the device and are not sent to a developer-operated server. The app does not connect users with real people. Before publishing the final build, verify that any newly added libraries or services do not change this behavior; update this section if they do.

4. Retention and deletion

Information is stored in the app's local storage. Progress may be reset from within the app where supported. Uninstalling the app generally removes local app data; Android backup settings may allow certain data to be restored by the operating system. For questions about data deletion, contact uliamarudova804@gmail.com.

5. Children

Glove is intended for people aged 18 and older and is not designed for children.

6. Security and updates

We aim to limit data processing to what is needed for app features. This policy may be revised if app functionality changes. The current version will be available at the same public URL.
